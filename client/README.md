# RuneStone Enterprise Treasury Client

React 19 single-page application built with Vite and Tailwind CSS (Dark Noir brutalist aesthetic).

## Features
- **Corporate Treasury Dashboard**: Three-bucket account balance inspection (`Available`, `Held`, `Posted`), single idempotent transfers, and double-entry posting leg breakdowns.
- **Bulk CSV Payroll & Multi-Currency FX**: Real-time FX conversion quotes (`USD`, `EUR`, `GBP`, `INR`) and bulk CSV payroll batch upload with row-by-row reconciliation.
- **Sentinel AML Compliance Command Center**: Flagged balance hold queue, interactive SVG 5-hop recursive CTE circular loop visualizer, Gemini AI case dossiers, and 1-click official FinCEN SAR PDF dossier download.
- **Real-Time SSE Event Stream**: Live operational ticker in header for instant settlement, batch progress, and compliance alerts.

## Quickstart
```bash
npm install
npm run dev                # Starts Vite dev server on http://localhost:5173
npm run build              # Produces production bundle
```
